# HFW – QR-Baiting-Demo (Phishing Awareness)

Zwei Dateien bilden die Demo:
- `index.html` – harmlose Download-Seite («Unterlagen fürs Handy»)
- `Unterrichtsunterlagen_fuers_Handy.pdf` – das Gotcha-PDF («Jetzt wäre es zu spät …»)

## Auf GitHub Pages veröffentlichen (ca. 2 Minuten)
1. github.com → **New repository** → Name z. B. `hfw-unterlagen` → **Public** → **Create**.
2. **Add file → Upload files** → beide Dateien hochladen → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: **main** / **/(root)** → **Save**.
4. Nach ~1 Minute erscheint oben die Live-URL:
   `https://<dein-username>.github.io/hfw-unterlagen/`
5. URL im Handy testen → dann an Claude schicken → QR-Code wird passend erzeugt.

Tipp: Eine eigene (Sub-)Domain wie `unterlagen.eliasbraem.ch` wirkt noch glaubwürdiger als `github.io`.

## Ablauf im Unterricht
- Seite/QR projizieren, 2 Min «zu spät» kommen.
- Wer scannt und das PDF öffnet, sieht privat die Auflösung.
- Du löst gemeinsam auf: Baiting – Neugier + nützlich aussehender Köder.
